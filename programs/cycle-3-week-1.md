## Progression Protocol

| Scenario | Action |
|---|---|
| Hit top of rep range on ALL sets | +2.5kg next session (upper) / +5kg (lower) |
| Hit top of rep range on SOME sets | Repeat weight, aim for full completion |
| Miss bottom of rep range on 2+ sets | −5% weight, reassess form |
| 2 consecutive stalls on same exercise | Flag for exercise swap next cycle |
| DB maxed (27kg) + all sets at 15 reps | Add 4th set → then swap to barbell variant |
